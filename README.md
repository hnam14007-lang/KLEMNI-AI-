# KLEMNI AI — сайт студии парфюмерии

Одностраничный сайт премиального парфюмерного бренда. Чистый HTML / CSS / JS без сборки.

**Живая версия:** https://klemni-ai.higgsfield.app

## Графика

Все фотографии (hero-флакон, шесть флаконов коллекции, макро сырья, ателье, распыление) сгенерированы в Higgsfield на модели Nano Banana Pro и раздаются с хостинга Higgsfield: `https://klemni-ai.higgsfield.app/img/`. Чтобы перенести картинки в репозиторий, положите webp-файлы в `assets/img/` и замените базовый URL в `index.html`, `css/style.css` и константе `IMG_BASE` в `js/main.js`.

## Запуск локально

```bash
python3 -m http.server 8080
```

## Что внутри

- `index.html` — структура: hero, манифест, каталог, подбор аромата, ателье, отзывы, финальный CTA, окно заказа.
- `css/style.css` — дизайн-система (обсидиан, кость, дымчатое шампанское; Bodoni Moda + Jost), анимации, адаптив.
- `js/main.js` — данные ароматов, карточки, скролл-хореография (флакон, распыление, туман, параллакс), подбор по настроению, переключение объёма с пересчётом цены, окно заказа с маской телефона.

## Контент

Ароматы, ноты, цены по объёмам и теги подбора лежат в массиве `FRAGRANCES` в начале `js/main.js`.

## Заявки

Форма сохраняет заявку в `localStorage` (`klemni_orders`). Точка подключения бэкенда отмечена комментарием в обработчике `submit`.
