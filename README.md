# KLEMNI AI — сайт студии парфюмерии

Одностраничный сайт премиального парфюмерного бренда. Чистый HTML / CSS / JS без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
python3 -m http.server 8080
```

## Что внутри

- `index.html` — структура: hero, манифест, каталог, подбор аромата, преимущества, отзывы, финальный CTA, модальное окно заказа.
- `css/style.css` — дизайн-система (тёмная палитра, золото, стекло, blur), анимации, адаптив до 360px.
- `js/main.js` — данные ароматов, генерация карточек и SVG-флаконов, скролл-анимации (флакон, распыление, туман, параллакс), подбор по настроению, переключение объёма с пересчётом цены, модалка с маской телефона.

## Как править контент

Ароматы, ноты, цены по объёмам и теги подбора лежат в массиве `FRAGRANCES` в начале `js/main.js`.

## Отправка заказа

Форма сейчас сохраняет заявку в `localStorage` (`klemni_orders`). Точка подключения бэкенда отмечена комментарием в обработчике `submit` в `js/main.js`.
